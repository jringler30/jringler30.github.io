Where a reporting error could creep in

I built the relational schema for orders, shipments, invoices, and payments, then transformed it into a star schema for reporting. A join that repeats a sales line can inflate revenue. The validation checks compare row counts and revenue totals against the source, then compare each reporting line amount with the corresponding source line. The exact matches apply to this generated dataset.
