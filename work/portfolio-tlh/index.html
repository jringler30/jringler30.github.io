Portfolio TLH Optimizer

A Python and Streamlit simulator for comparing tax-aware rebalancing strategies.

View repository ↗

What happens when harvesting is switched on?

I built a portfolio optimization engine and Streamlit interface as part of the UT Austin capstone for Vise. It compares rebalancing rules using historical prices, tracks individual tax lots, and models wash-sale constraints.

The two rows below use the same 100/0 portfolio, the same bear-market scenario labeled 2007–2008, and the same absolute 10% rebalancing threshold.

Simulated results for one paired backtest

What this comparison shows

In this scenario, the harvesting run incurred higher execution costs and finished at a lower portfolio value. The simulator makes that tradeoff visible. The two rows describe one historical simulation with defined assumptions.
