Portfolio TLH Optimizer

A Python and Streamlit simulator for comparing tax-aware rebalancing strategies.

View repository ↗

What we built

I built a portfolio optimization engine and a Streamlit app to quantify potential tax savings. The simulator uses historical data to compare rebalancing rules, tracks tax lots, and models wash-sale constraints.

What the project shows

The dashboard puts return, drawdown, and risk-adjusted performance side by side, so users can see how a strategy behaves across scenarios.
